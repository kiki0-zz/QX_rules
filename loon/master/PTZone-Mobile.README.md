0.2.3：列表中断时先自动重新获取当前页，相当于后台刷新一次。完整返回时直接更新列表并清除提示。前 5 页在整页重取仍不完整时继续分段补齐，后续页可点「补齐本页」。

## 安装与更新

在 Loon 插件列表添加或更新现有插件：

```text
https://raw.githubusercontent.com/kiki0-zz/QX_rules/main/loon/master/PTZone-Mobile.plugin
```

要求 **Loon 3.5.1 (983)+ / iOS 15.4+**。启用插件、脚本及 MitM，本机安装并完全信任 Loon 证书。插件仅声明 `ptzone.xyz`。Safari 对本站关闭「请求桌面网站」。

更新插件和脚本后，关闭旧的 PTZone 标签页，再重新打开网站。页面状态应显示 `移动版 · v0.2.4`，插件的脚本地址带 `?v=0.2.4`。使用原来的入口链接更新即可。

配套运行脚本：`https://raw.githubusercontent.com/kiki0-zz/QX_rules/main/loon/master/ptzone-mobile.js`。CSS 和浏览器代码已嵌入，不需要另行加载 CSS / browser.js。

## 原站行为与恢复

保留原始下载、收藏、搜索、排序、分页及表单节点/处理函数。「显示设置」可以全站恢复原版、仅为当前类页面关闭适配、重置本机显示偏好。切换原版会撤销布局移动、标记、添加的控件及 viewport，已填写的表单内容继续保留。关闭插件前可先切原版，再关闭插件并重新载入。

没有自动签到、下载、收藏、发送、发帖、兑换或保存账户设置；没有读取 Cookie/Passkey、网络上报和日志功能。显示偏好只记录在本站本机 localStorage。只改写白名单内的 GET HTML 文档；下载端点、API、附件、XHR、Range、二进制及其他主机不改写。强制 CSP 和未知模板保留原版，不移除安全策略。

## 验证范围

本次通过 **382 项 DOM 行为、响应条件及构建一致性检查**。新增回归覆盖 46 条搜索结果中一条统计缺失的恢复，以及重取仍缺失或失败时保留结果。原有检查覆盖前 5 页补齐、分段重复后的整页重取、筛选条件、签到、原版恢复及响应规则。测试使用按实站结构制作的虚拟记录。

**本次尚未完成浏览器尺寸回放和 iPhone Safari + Loon 真机验收。** 仓库提供 320/375/390/430px × 8 视图的浏览器回放检查脚本，不能将脚本存在等同于本轮全部通过。没有执行真实下载、收藏写入或帖子/消息提交。

实站第 1、2 页可返回完整列表，第 3–5 页出现不同位置中断，并且最后一条仅生成分类/标题。中断位置与上游评分渲染调用相符，尚未获得站点服务端日志，不能确定具体异常。已实测原站支持 `pageSize` 及对应记录范围。回归中的前 5 页分段补齐测试使用模拟中断页面，每页准确恢复 50 条、顺序一致、没有重复；这不等同于 iPhone 真机或实站全部统计数据已验收。客户端无法补造服务端没有返回的评分和统计。

手机验收建议：首页折叠/展开 → 种子搜索和免费/活种/收藏筛选 → 翻页/排序 → 详情下载/收藏（由用户按需操作）→ 论坛/我的 → 原版切换。反馈时提供页面路径、iOS/Loon 版本和截图；不要发送 Cookie、密码、Passkey 或带签名的下载/RSS 地址。

## 维护

行为代码保存在 `loon/master/ptzone-mobile.browser.js`，CSS 以 `loon/master/ptzone-mobile.css` 为准。修改后在仓库根目录运行：

```sh
node tools/ptzone-mobile/build.mjs
```

构建会同步 CSS、浏览器代码、响应脚本和插件版本。DOM 回归需要 Node.js 和 `linkedom`：

```sh
node tools/ptzone-mobile/dom-test.mjs
```

浏览器回归需要 `playwright` 和 Chromium；可通过 `PTZONE_CHROMIUM` 指定可执行文件：

```sh
node tools/ptzone-mobile/test.mjs
```

维护时先对问题页面关闭适配，检查实际模板后再更新映射，回归原链接、表单及异步状态。不扩大规则覆盖未检查的 API/动作端点。

官方格式依据：[Loon Script](https://nsloon.app/docs/Script/script_v2/)、[Script API](https://nsloon.app/docs/Script/script_api/)、[MitM](https://nsloon.app/docs/MitM/)。
